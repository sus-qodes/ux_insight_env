🎮 Custom Interactive Playground

Welcome to the Custom Playground! This is your dedicated space to experiment with the UX Insight Analyst environment with full customization and control.

✨ Available Features
📊
Analytics Testing
Test UX analysis with custom page analytics data and heatmaps.
🔍
Issue Detection
Identify and document UX issues with detailed findings and recommendations.
📈
Performance Metrics
Track improvement metrics and evaluate impact estimates for fixes.
🎯
Custom Scenarios
Create and test custom UX scenarios with your own parameters.
🔗 Differences from OpenEnv Playground

This custom playground offers enhanced features and customization options beyond the standard OpenEnv template:

  • ✅ Custom UI Components - Tailored interface for UX analysis workflows
  • ✅ Advanced Filtering - More granular control over test scenarios
  • ✅ Custom Reports - Generate detailed analysis reports with insights
  • ✅ Extended Logging - More detailed execution logs for debugging
  • ✅ Custom Themes - Choose from multiple UI themes and layouts
🔌 API Integration

This playground connects to the same backend environment as OpenEnv, ensuring consistent behavior and results.

POST /reset - Initialize a new episode GET /state - Retrieve current environment state POST /step - Submit an action and get feedback GET /ground_truth - Access teaching mode answers
