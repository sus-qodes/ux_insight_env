UX Insight Analyst Environment

A reinforcement learning environment that benchmarks LLM agents on the real-world task of interpreting e-commerce behavioral analytics data and producing actionable UX recommendations.

Try Live Demo Read Documentation View Baselines

The Problem

Most agent benchmarks test code generation, search, support, or planning. None test behavioral analytics interpretation -- the daily work of UX analysts and product teams at every e-commerce company.

This environment simulates the workflow of reviewing analytics from tools like Microsoft Clarity, Hotjar, and Mixpanel: inspecting heatmaps, rage-click reports, funnel drop-offs, device splits, and session recordings to separate real friction from noise.

The agent receives synthetic but realistic StyleMart e-commerce analytics data. It must identify which pages have genuine UX problems, classify them correctly, assess severity, and produce specific recommendations -- while resisting false positives from normal behavior patterns.

Dense, multi-component reward signals provide partial credit across five grading dimensions, with penalties for duplicate findings, overconfident wrong answers, and vague recommendations.

How It Works

Reset

The environment generates deterministic analytics data for a sequence of pages using embedded ground-truth problems and red herrings.

Observe

The agent receives page analytics: session counts, bounce rates, scroll depth, heatmap zones, behavioral signals, funnel data, and session recording summaries.

Act

The agent submits a structured finding: finding type, affected element, issue category, severity, recommendation, fix category, impact estimate, and confidence.

Grade

The environment grades the finding against embedded ground truth across five weighted dimensions. Dense partial credit -- not binary pass/fail.

Iterate

The agent advances to the next page with grader feedback. After all pages, episode-level bonuses and penalties are applied.

Tasks

Task Steps Description Challenge
Easy 1 One page with a single clear, high-signal UX issue such as a rage click or dead click. Signal identification
Medium 3 Three pages with different severity levels. Requires multi-step reasoning and prioritization. Severity assessment and ranking
Hard 6 Six-page funnel audit with real issues, red herrings, and clean pages mixed together. False-positive resistance and cross-page reasoning

50 problem templates across 10 page types and 10 issue categories. Deterministic seeded generation ensures reproducibility.

Key Findings

Signal Identification Is Reliable

Large LLMs reliably identify high-signal UX issues like rage clicks and dead clicks. The easy task (single obvious issue) is consistently solved with scores above 0.85.

Prioritization Is The Hard Part

The medium task (multi-page severity ranking) produces the lowest scores. Models struggle to correctly rank critical vs. high vs. medium severity across pages.

Red-Herring Resistance Varies

The hard task includes red herrings (e.g., high exit rate on order confirmation page). Larger models show better false-positive resistance, smaller models tend to over-flag.

Recommendation Quality Lags

Even when models correctly identify issues, recommendation specificity is often weak. Generic advice ("improve the UX") scores poorly; element-specific changes score well.
