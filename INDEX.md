## 🔑 Core Concepts

### Episode
A single session where an agent analyzes 1 (easy), 3 (medium), or 6 (hard) pages and submits a finding per page.

**Lifecycle**: reset() → observation → action → step() → feedback → repeat → done

### Ground Truth
The embedded problem metadata that the grader uses to evaluate submissions. Includes problem type, severity, expected keywords, expected fix category, whether it's a red herring, etc.

### Determinism
The same seed + task_id always produces identical:
- Page analytics data
- Embedded problems
- Expected recommendations
- Expected impact estimates

This enables reproducible evaluation across runs.

### Red Herring
A page with suspicious metrics that LOOK like a problem but are actually normal behavior. For example, high exit rate on an order confirmation page is normal, not a UX issue.

### Grade vs Reward
- **Grade** (0.0-1.0): How well the submission matches the ground truth
- **Reward** (−0.5 to 1.0): Step grade + step bonuses
- **Cumulative Score** (0.0-1.0): Average of all episode rewards

### Teaching Mode
The `/ground_truth` endpoint returns the expected answer for the current page. Clients can:
1. Call it to understand what the expected answer is
2. Use it in the playground to auto-fill forms for learning
3. Use it for supervised learning / SFT dataset generation

## 🚀 Quick Start

### Run Locally
```bash
pip install -r server/requirements.txt
uvicorn server.app:app --host 0.0.0.0 --port 7860
# Open http://localhost:7860/web
```

### Run in Docker
```bash
docker build -t ux-insight-env .
docker run --rm -p 7860:7860 ux-insight-env
# Open http://localhost:7860/web
```

### Run Tests
```bash
pytest server/tests/test_grader.py -v
```

### Test API
```bash
curl -X POST http://localhost:7860/reset -H "Content-Type: application/json" -d '{"seed": 101, "episode_id": "easy"}'
```

## ✨ Key Strengths of This System

1. **Deterministic**: Same seed → same data, enables reproducible benchmarks
2. **Dense Grading**: Per-step rewards (not just terminal), guides learning
3. **Real-World**: UX analytics interpretation, practical workflow
4. **Sophisticated**: 5-component scoring with anti-exploit penalties
5. **Teaching-Ready**: `/ground_truth` endpoint enables supervised learning
6. **Production-Grade**: Docker-ready, fully tested, cleanly architected
7. **Well-Documented**: Three levels of documentation for different audiences
