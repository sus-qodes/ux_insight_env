## System Overview

The **UX Insight Analyst Environment** is an OpenEnv-based reinforcement learning environment that simulates the work of a UX analyst at an e-commerce company reviewing behavioral analytics data.

### Key Characteristics
- **Type**: OpenEnv RL Environment
- **Domain**: UX/Analytics Interpretation
- **Framework**: FastAPI + OpenEnv
- **Deployment**: Docker (Hugging Face Spaces)
- **Determinism**: 100% seed-based reproducibility
- **Tasks**: Easy (1 step), Medium (3 steps), Hard (6 steps)

## Backend Architecture

### Component Breakdown

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    BACKEND COMPONENT ARCHITECTURE                           │
└─────────────────────────────────────────────────────────────────────────────┘

1. SERVER ENTRY POINT (server/app.py)
   ├─ FastAPI application created by OpenEnv factory: create_app()
   ├─ Imports: UXInsightEnvironment, UXAction, UXObservation
   ├─ Registers OpenEnv routes (/reset, /step, /state, /schema)
   ├─ Removes default Gradio UI routes
   ├─ Adds custom routes:
   │  ├─ GET  / ──────────► index.html (landing page)
   │  ├─ GET  /web ───────► playground.html (interactive UI)
   │  ├─ GET  /documentation ─► docs.html
   │  ├─ GET  /ground_truth ──► Teaching mode endpoint
   │  └─ GET  /health ───────► Docker health check
   └─ Runs on 0.0.0.0:7860 (Docker) or localhost:8000 (dev)

2. ENVIRONMENT ENGINE (server/environment.py)
   │
   ├─ CLASS: UXInsightEnvironment(Environment)
   │  ├─ Extends OpenEnv's abstract Environment
   │  ├─ Attributes:
   │  │  ├─ _pages_data: List[PageAnalyticsData]
   │  │  ├─ _embedded_problems: List[Dict] (ground truth)
   │  │  ├─ _current_step: int
   │  │  ├─ _task_id: str ("easy" | "medium" | "hard")
   │  │  ├─ _findings: List[FindingEntry] (agent submissions)
   │  │  ├─ _episode_rewards: List[float]
   │  │  └─ rubric: UXAnalystRubric
   │  │
   │  ├─ METHOD: reset(seed, episode_id, task_id) → UXObservation
   │  │  ├─ Validates/selects task_id
   │  │  ├─ Generates deterministic episode data (seed + task_id)
   │  │  ├─ Extracts ground truth for first page
   │  │  ├─ Populates finding with _generate_recommendation() + _generate_impact_estimate()
   │  │  └─ Returns UXObservation for step 1
   │  │
   │  ├─ METHOD: step(action: UXAction) → UXObservation
   │  │  ├─ Validates action (category, fix, consistency)
   │  │  ├─ Grades action via grade_step()
   │  │  ├─ Computes reward via compute_step_reward()
   │  │  ├─ Records FindingEntry
   │  │  ├─ Moves to next page (_current_step += 1)
   │  │  ├─ If done: computes final bonus via grade_episode()
   │  │  └─ Returns UXObservation (next page or done=True)
   │  │
   │  ├─ PROPERTY: state
   │  │  └─ Returns UXState (internal, hidden from agent)
   │  │
   │  └─ HELPER FUNCTIONS:
   │     ├─ _validate_action() → Error message or None
   │     └─ _build_observation() → Construct UXObservation with ground truth
   │
   │
   ├─ HELPER FUNCTIONS (module-level)
   │  ├─ _generate_recommendation(problem: Dict) → str
   │  │  └─ Creates 20+ word recommendation with keywords
   │  │
   │  └─ _generate_impact_estimate(problem: Dict) → str
   │     └─ Creates metric-based impact with percentage ranges
   │
   │
   └─ CONSTANTS
      ├─ TASK_IDS = ["easy", "medium", "hard"]
      ├─ MAX_STEPS_BY_TASK = {"easy": 1, "medium": 3, "hard": 6}
      └─ TASK_DESCRIPTIONS = {...}

3. GRADING ENGINE (server/grader.py)
   │
   ├─ grade_step(action, problems, page) → float [0.0-1.0]
   │  ├─ Separates real problems from red herrings
   │  ├─ Cases:
   │  │  ├─ Case 1: Page has NO problems → Check if action.finding_type == "no_issue"
   │  │  │           Score: (0.50) + (0.30 if category=normal_behavior) + (0.20 if severity=none)
   │  │  │
   │  │  ├─ Case 2: Page has 1+ real problems → Match action to best problem
   │  │  │           Scores:
   │  │  │           • Element match: 25% (keyword overlap)
   │  │  │           • Category match: 20% (exact or related)
   │  │  │           • Severity: 15% (exact=1.0, off-by-one=0.5)
   │  │  │           • Recommendation: 25% (keyword coverage + length + element mention)
   │  │  │           • Fix category: 15% (exact or compatible)
   │  │  │
   │  │  ├─ Case 3: Agent detects wrong/phantom problem → Penalty
   │  │  │           Score reduced for false positive
   │  │  │
   │  │  └─ Case 4: Agent reports ambiguous → Partial credit (0.10-0.30)
   │  │
   │  └─ Anti-exploit penalties:
   │     ├─ Duplicate finding: -0.40
   │     ├─ Inconsistency (finding_type ≠ severity): -0.20
   │     ├─ Over-confidence on wrong: -0.10
   │     └─ Vague recommendation: -0.15
   │
   ├─ compute_step_reward(grade, action, state) → float
   │  ├─ Base: grade (0.0-1.0)
   │  ├─ Confidence bonus: +0.05 if confidence ≥ 0.8 and grade ≥ 0.7
   │  ├─ Consistency bonus: +0.02 if action consistent
   │  └─ Final: clipped to [-0.5, 1.0]
   │
   ├─ grade_episode(state, task_id) → float
   │  ├─ Holistic end-of-episode bonus
   │  ├─ Medium/Hard: +0.10 if findings ordered by severity
   │  ├─ Hard only: +0.10 for red herring handling
   │  ├─ Hard only: +0.05 for impact estimate quality
   │  ├─ All: -0.05 per low-score finding
   │  └─ Range: [-0.10, +0.25]
   │
   └─ generate_grader_feedback(grade, action, problems) → str
      └─ Natural language feedback based on grade and problem type

4. DATA GENERATION (server/data_generator.py)
   │
   ├─ generate_episode_data(seed, task_id) → (pages, problems)
   │  ├─ Initializes seeded RNG
   │  ├─ Selects pages based on task_id:
   │  │  ├─ Easy: 1 page (highest-signal problem)
   │  │  ├─ Medium: 3 pages (mixed signal + clear problems)
   │  │  └─ Hard: 6 pages (includes red herrings + clean pages)
   │  │
   │  ├─ For each page:
   │  │  ├─ Generates PageAnalyticsData:
   │  │  │  ├─ Heatmap zones (click density %)
   │  │  │  ├─ Behavioral signals (rage clicks, dead clicks, etc.)
   │  │  │  ├─ Funnel steps (if applicable)
   │  │  │  ├─ Session recording summary (templated NL)
   │  │  │  ├─ Mobile vs desktop split
   │  │  │  └─ Bounce rates, scroll depth percentiles
   │  │  │
   │  │  └─ Embeds problem metadata:
   │  │     ├─ problem_id (unique)
   │  │     ├─ problem_type (enum)
   │  │     ├─ affected_element (string)
   │  │     ├─ severity (critical/high/medium/low)
   │  │     ├─ expected_keywords (List[str])
   │  │     ├─ expected_fix_category (string)
   │  │     └─ red_herring (boolean) - page with suspicious metrics but normal behavior
   │  │
   │  └─ Returns:
   │     ├─ pages: List[PageAnalyticsData]
   │     └─ problems: List[Dict] with metadata
   │
   └─ Deterministic: Same (seed, task_id) → Same pages + problems every time

5. PROBLEM TEMPLATES (server/problem_templates.py)
   │
   ├─ Constants:
   │  ├─ PROBLEM_TEMPLATES: Dict[str, Dict] - 50+ problem definitions
   │  ├─ ALL_PAGES: List[str] - Available pages (Product, Checkout, Cart, etc.)
   │  ├─ PAGE_URL_PATTERNS: Dict[str, str] - URL patterns per page
   │  ├─ PAGE_HEATMAP_ZONES: Dict[str, List[str]] - Zones per page
   │  ├─ RELATED_CATEGORIES: Set[Tuple] - Related problem categories
   │  └─ COMPATIBLE_FIXES: Set[Tuple] - Compatible fix combinations
   │
   └─ Problem structure:
      ├─ problem_id: Unique ID
      ├─ problem_type: One of [rage_click, dead_click, funnel_dropoff, ...]
      ├─ affected_element: UI element name
      ├─ severity: critical/high/medium/low
      ├─ expected_keywords: Keywords agent should mention
      ├─ expected_fix_category: Recommended fix type
      └─ red_herring: Boolean (normal behavior that looks like a problem)

6. RUBRIC SYSTEM (server/rubrics.py - RFC 004)
   │
   └─ UXAnalystRubric class
      ├─ Provides rubric information for RL training framework integration
      ├─ Methods:
      │  ├─ get_task_rubric() → Dimensions, weight, max points
      │  └─ compute_score() → Applies rubric to grading output
      └─ Enables deterministic reward function for RL training
```

```
STEP 2: ACTION (Step 1 of 1 for Easy)
  ┌─────────────────────────────────────────────────────────────────────┐
  │ POST /step { UXAction }                                             │
  │                                                                      │
  │ ┌─ FastAPI Handler ──────────────────────────────────────────────┐  │
  │ │  1. OpenEnv framework receives request                         │  │
  │ │  2. Calls environment.step(action)                            │  │
  │ │                                                                 │  │
  │ │  ┌─ UXInsightEnvironment.step(action) ─────────────────────┐  │  │
  │ │  │  1. Validate action → _validate_action(action)          │  │  │
  │ │  │     If invalid: step_grade = 0.0, step_reward = -0.2    │  │  │
  │ │  │     Else:                                                 │  │  │
  │ │  │  2. Grade action:                                         │  │  │
  │ │  │     current_page_problems = filter(_embedded_problems)   │  │  │
  │ │  │     step_grade = grade_step(action, problems, page)      │  │  │
  │ │  │                                                            │  │  │
  │ │  │     ┌─ grade_step() ────────────────────────────────────┐ │  │  │
  │ │  │     │  1. Separate real problems from red herrings       │ │  │  │
  │ │  │     │  2. case: Page has NO problems                     │ │  │  │
  │ │  │     │     ├─ If action.finding_type == "no_issue": +50% │ │  │  │
  │ │  │     │     ├─ If category == "normal_behavior": +30%     │ │  │  │
  │ │  │     │     └─ If severity == "none": +20%                │ │  │  │
  │ │  │     │  3. case: Page has 1+ real problems               │ │  │  │
  │ │  │     │     ├─ Find best match problem                    │ │  │  │
  │ │  │     │     ├─ Element score (25%): keyword overlap       │ │  │  │
  │ │  │     │     ├─ Category score (20%): exact or related     │ │  │  │
  │ │  │     │     ├─ Severity score (15%): exact or off-by-one  │ │  │  │
  │ │  │     │     ├─ Recommendation score (25%):                │ │  │  │
  │ │  │     │     │   • Keyword coverage                        │ │  │  │
  │ │  │     │     │   • Length bonus (>=20 words)               │ │  │  │
  │ │  │     │     │   • Element mention                         │ │  │  │
  │ │  │     │     └─ Fix category score (15%): exact or compat  │ │  │  │
  │ │  │     │  4. Apply anti-exploit penalties:                 │ │  │  │
  │ │  │     │     • Duplicate: -40%                             │ │  │  │
  │ │  │     │     • Inconsistency: -20%                         │ │  │  │
  │ │  │     │     • Over-confidence: -10%                       │ │  │  │
  │ │  │     │     • Vague rec: -15%                             │ │  │  │
  │ │  │     │  5. Return score [0.0, 1.0]                       │ │  │  │
  │ │  │     └──────────────────────────────────────────────────┘ │  │  │
  │ │  │                                                            │  │  │
  │ │  │  3. Compute reward:                                        │  │  │
  │ │  │     step_reward = compute_step_reward(grade, action, state)│ │  │  │
  │ │  │     • Base: step_grade [0.0-1.0]                         │ │  │  │
  │ │  │     • Confidence bonus: +0.05 if conf>=0.8 && grade>=0.7 │ │  │  │
  │ │  │     • Consistency bonus: +0.02 if consistent             │ │  │  │
  │ │  │     • Final: clipped to [-0.5, 1.0]                      │ │  │  │
  │ │  │                                                            │  │  │
  │ │  │  4. Record finding:                                        │  │  │
  │ │  │     findings.append(FindingEntry(...))                   │ │  │  │
  │ │  │     episode_rewards.append(step_reward)                  │ │  │  │
  │ │  │                                                            │  │  │
  │ │  │  5. Move to next step:                                    │  │  │
  │ │  │     _current_step += 1  (now 1)                          │ │  │  │
  │ │  │     Check if done: current_step >= len(pages_data)      │ │  │  │
  │ │  │     done = True (for Easy: 1 step total)                 │ │  │  │
  │ │  │                                                            │  │  │
  │ │  │  6. If done:                                              │  │  │
  │ │  │     final_bonus = grade_episode(state, "easy")           │ │  │  │
  │ │  │     episode_rewards.append(final_bonus)                  │ │  │  │
  │ │  │     _is_done = True                                      │ │  │  │
  │ │  │                                                            │  │  │
  │ │  │  7. Cumulative score:                                      │  │  │
  │ │  │     cumulative = sum(episode_rewards) / max_steps        │ │  │  │
  │ │  │                                                            │  │  │
  │ │  │  8. Return observation with done=True                     │  │  │
  │ │  └─────────────────────────────────────────────────────────┘ │  │
  │ │                                                                 │  │
  │ │  3. Return observation to client                             │  │
  │ └─────────────────────────────────────────────────────────────────┘ │
  │                                                                      │
  │ Client receives:                                                    │
  │ {                                                                   │
  │   "observation": UXObservation {                                    │
  │     "current_step": 1,                                              │
  │     "done": true,  ← Episode complete                              │
  │     "reward": 0.82,  ← step_reward + final_bonus                   │
  │     "cumulative_score": 0.82,  ← Final episode score               │
  │     "grader_feedback": "Good identification..."                    │
  │     "findings_so_far": [FindingEntry {...}]                        │
  │   }                                                                  │
  │ }                                                                   │
  └─────────────────────────────────────────────────────────────────────┘
     ▼
  [UI Shows "Episode Complete" with Score 0.82]
     ▼
  [User Can Click Reset for New Episode]
```

```
                    ┌────────────┴────────────┐
                    │                         │
        ┌──────────►│ done?                   │◄──────────┐
        │           │                         │           │
        │           └─────┬──────────┬────────┘           │
        │                 │ No       │ Yes                │
        │                 ▼         ▼                     │
        │          More     ┌──────────────────┐ Yes     │
        │          pages    │  done=true?       │         │
        │          ┌────────┤ Compute final    │         │
        │          │        │ bonus             │         │
        │          │        │ _is_done = True   │         │
        │          │        └──────────┬───────┘         │
        │          │                   │                  │
        │          │                   ▼                  │
        │          ▼        ┌──────────────────────────┐ │
        │   ┌─────────────┐ │   EPISODE COMPLETE       │ │
        │   │ OBSERVATION │ │ ──────────────────────  │ │
        │   │  (Step N)   │ │ done = True              │ │
        │   │ done = False│ │ reward = accumulated     │ │
        │   │             │ │ cumulative_score = final │ │
        │   └─────────────┘ │ grader_feedback ready    │ │
        │        ▲          │ Can only RESET now      │ │
        │        │          └───────────┬──────────────┘ │
        │        │                      │                │
        │        └──────────────────────┼────────────────┘
        │                               │
        │                               ▼
        │                    ┌──────────────────┐
        │                    │   Next Episode?  │
        │                    │                  │
        │                    │ [RESET] button   │
        │                    │ enabled          │
        │                    └──────┬───────────┘
        │                           │
        └───────────────────────────┘
                (cycle repeats)

═══════════════════════════════════════════════════════════════════════

IMPORTANT STATE INVARIANTS:

1. Before reset():
   - No episode active
   - can only call /reset

2. After reset() → after step() [NOT done]:
   - _current_step ∈ [0, len(pages_data) - 1]
   - _is_done = False
   - can call /step or /ground_truth

3. After step() with done=True:
   - _current_step = len(pages_data)
   - _is_done = True
   - can only call /reset (other /step calls → error)

4. Error handling:
   - If /step called with _is_done = True → return done=True, reward=-0.1
   - If /step called without reset() → auto-reset internally
```

## Grading System

### Reward Calculation Flow

```
┌─────────────────────────────────────────────────────────────────────┐
│                  GRADING & REWARD PIPELINE                          │
└─────────────────────────────────────────────────────────────────────┘

INPUT: UXAction (agent's finding)
OUTPUT: float [0.0-1.0] (step reward)

┌──────────────────────────────────────────────────────────────────────┐
│ 1. VALIDATION                                                         │
├──────────────────────────────────────────────────────────────────────┤
│  Check:                                                               │
│  • issue_category in allowed categories ✓                            │
│  • fix_category in allowed categories ✓                              │
│  • Consistency: finding_type="no_issue" → severity="none" ✓          │
│  • Consistency: finding_type="issue" → fix_category≠"no_fix_needed" │
│                                                                       │
│  If invalid:                                                         │
│    ├─ step_grade = 0.0                                              │
│    ├─ step_reward = -0.2                                            │
│    └─ Return feedback: "Invalid action rejected: ..."                │
│                                                                       │
│  If valid: Proceed to grading                                        │
└──────────────────────────────────────────────────────────────────────┘
                            ▼
┌──────────────────────────────────────────────────────────────────────┐
│ 2. GRADE_STEP()                                                      │
├──────────────────────────────────────────────────────────────────────┤
│                                                                       │
│  CASE ANALYSIS (based on ground truth problems):                    │
│                                                                       │
│  ┌─ CASE 1: Page has NO real problems (clean page or red herring) ─┐│
│  │  ├─ If action.finding_type == "no_issue":                       ││
│  │  │  ├─ score += 0.50 ✓                                          ││
│  │  │  ├─ If action.issue_category == "normal_behavior": score+=30││
│  │  │  ├─ If action.severity == "none": score += 0.20             ││
│  │  │  └─ Total: 0.50 - 1.00                                      ││
│  │  │                                                               ││
│  │  ├─ Elif action.finding_type == "ambiguous":                    ││
│  │  │  └─ score += 0.20 (partial credit for uncertainty)           ││
│  │  │                                                               ││
│  │  └─ Else (finding_type == "issue"):                             ││
│  │     └─ score = 0.0 (FALSE POSITIVE penalty)                     ││
│  └───────────────────────────────────────────────────────────────────┘│
│                                                                       │
│  ┌─ CASE 2: Page has 1+ real problems ──────────────────────────────┐│
│  │  ├─ Find best matching problem:                                 ││
│  │  │  ├─ elem_score = similarity("action.element", "problem.elem")││
│  │  │  ├─ cat_score = 1.0 if exact, 0.5 if related, 0.0 if not    ││
│  │  │  └─ combined = 0.6 * elem_score + 0.4 * cat_score           ││
│  │  │     Keep problem if combined > 0.15 (minimum threshold)      ││
│  │  │                                                               ││
│  │  ├─ If NO good match:                                           ││
│  │  │  └─ Agent found phantom/wrong problem → score = 0.0          ││
│  │  │                                                               ││
│  │  └─ If good match found:                                        ││
│  │     ├─ Calculate component scores (25%, 20%, 15%, 25%, 15%):   ││
│  │     │                                                            ││
│  │     │  1. ELEMENT IDENTIFICATION (25%)                          ││
│  │     │     ├─ Jaccard-like token overlap                         ││
│  │     │     ├─ Perfect (100% overlap): 0.25                       ││
│  │     │     ├─ Partial (60% overlap): 0.15                        ││
│  │     │     └─ No match: 0.0                                      ││
│  │     │                                                            ││
│  │     │  2. ISSUE CATEGORY (20%)                                  ││
│  │     │     ├─ Exact match: 0.20                                  ││
│  │     │     ├─ Related (in RELATED_CATEGORIES): 0.10              ││
│  │     │     └─ Unrelated: 0.0                                     ││
│  │     │                                                            ││
│  │     │  3. SEVERITY (15%)                                        ││
│  │     │     ├─ Exact match (c=c, h=h, etc.): 1.0 → 0.15          ││
│  │     │     ├─ Off-by-one (c vs h, h vs m, etc.): 0.5 → 0.075    ││
│  │     │     └─ Wrong (c vs l, etc.): 0.0                         ││
│  │     │                                                            ││
│  │     │  4. RECOMMENDATION (25%)                                  ││
│  │     │     ├─ Keyword coverage: % of expected_keywords in rec   ││
│  │     │     ├─ Length bonus: +0.2 if >= 20 words (else ×0.5)    ││
│  │     │     ├─ Element mention: +0.2 if element in rec            ││
│  │     │     └─ cap at 0.25                                        ││
│  │     │                                                            ││
│  │     │  5. FIX CATEGORY (15%)                                    ││
│  │     │     ├─ Exact match: 0.15                                  ││
│  │     │     ├─ Compatible (in COMPATIBLE_FIXES): 0.075            ││
│  │     │     └─ Incompatible: 0.0                                  ││
│  │     │                                                            ││
│  │     └─ base_score = sum of components [0.0, 1.0]               ││
│  │                                                                  ││
│  │     ├─ ANTI-EXPLOIT PENALTIES (subtracted):                     ││
│  │     │  ├─ Duplicate finding (same elem+category on prior page)  ││
│  │     │  │  └─ penalty -= 0.40                                     ││
│  │     │  ├─ Inconsistency (finding_type≠severity meaning)         ││
│  │     │  │  └─ penalty -= 0.20                                     ││
│  │     │  ├─ Over-confidence on wrong (grade<0.3 but conf>0.8)     ││
│  │     │  │  └─ penalty -= 0.10                                     ││
│  │     │  └─ Minimal recommendation (< 10 chars)                    ││
│  │     │     └─ penalty -= 0.15                                     ││
│  │     │                                                            ││
│  │     └─ step_grade = max(min(base_score - penalties, 1.0), -0.5)││
│  └───────────────────────────────────────────────────────────────────┘│
│                                                                       │
│  ┌─ CASE 3: Ambiguous finding ──────────────────────────────────────┐│
│  │  └─ Partial credit (0.10-0.30) depending on degree of matching  ││
│  └───────────────────────────────────────────────────────────────────┘│
│                                                                       │
└──────────────────────────────────────────────────────────────────────┘
                            ▼
┌──────────────────────────────────────────────────────────────────────┐
│ 3. COMPUTE_STEP_REWARD()                                             │
├──────────────────────────────────────────────────────────────────────┤
│                                                                       │
│  Base reward = step_grade [0.0-1.0]                                 │
│                                                                       │
│  Bonuses:                                                             │
│  ├─ Confidence bonus: +0.05 if confidence ≥ 0.8 AND step_grade≥0.7 │
│  ├─ Consistency bonus: +0.02 if action passes all validations       │
│  └─ Momentum bonus: +0.01 for each prior high-confidence finding    │
│                                                                       │
│  Final reward = base + bonuses                                       │
│                clipped to [-0.5, 1.0]                                │
│                                                                       │
│  Example:                                                             │
│  ├─ step_grade = 0.80                                               │
│  ├─ confidence = 0.90 ✓ (high) + 0.05 = 0.85                       │
│  ├─ consistent = True + 0.02 = 0.87                                 │
│  ├─ clipped to [0.0, 1.0] = 0.87                                    │
│  └─ step_reward = 0.87                                              │
│                                                                       │
└──────────────────────────────────────────────────────────────────────┘
                            ▼
┌──────────────────────────────────────────────────────────────────────┐
│ 4. RECORD FINDING & CHECK TERMINATION                                │
├──────────────────────────────────────────────────────────────────────┤
│                                                                       │
│  ├─ Add FindingEntry to findings list                               │
│  ├─ Add step_reward to episode_rewards                              │
│  ├─ _current_step += 1                                              │
│  ├─ Check if episode done:                                          │
│  │  ├─ done = (_current_step >= len(pages_data))                   │
│  │  └─ If done:                                                     │
│  │     ├─ _is_done = True                                          │
│  │     ├─ Proceed to Grade Episode (next step)                     │
│  │     └─ Skip if not done                                         │
│  │                                                                  │
│  └─ Return (step_grade, step_reward, done)                         │
│                                                                       │
└──────────────────────────────────────────────────────────────────────┘
                            ▼
┌──────────────────────────────────────────────────────────────────────┐
│ 5. GRADE_EPISODE() [only if done=True]                               │
├──────────────────────────────────────────────────────────────────────┤
│                                                                       │
│  Holistic end-of-episode bonuses:                                    │
│                                                                       │
│  ├─ Priority Ranking (medium/hard only):                             │
│  │  ├─ Check if findings ordered by severity (critical→low)         │
│  │  ├─ If yes: bonus += 0.10                                        │
│  │  └─ If no: bonus += 0.0                                          │
│  │                                                                  │
│  ├─ Red Herring Handling (hard only):                                │
│  │  ├─ For each red herring page:                                   │
│  │  │  ├─ If finding_type="no_issue": +0.10 per page               │
│  │  │  └─ Else: -0.05 per page (false positive)                    │
│  │  │                                                               │
│  │  └─ Total red herring component: [-0.10, +0.10]                 │
│  │                                                                  │
│  ├─ Impact Estimate Quality (hard only):                             │
│  │  ├─ Check if impact_estimates include percentages + metrics     │
│  │  ├─ If good quality: bonus += 0.05                              │
│  │  └─ If poor: bonus += 0.0                                       │
│  │                                                                  │
│  └─ False Positive Penalty (all):                                   │
│     ├─ For each finding with step_grade < 0.1:                     │
│     │  └─ penalty -= 0.05                                          │
│     └─ Total false positive component: [−0.30, 0]                  │
│                                                                       │
│  final_bonus = priority + red_herring + impact - false_pos          │
│  final_bonus clipped to [-0.10, +0.25]                              │
│                                                                       │
│  Example:                                                             │
│  ├─ priority bonus: 0.10                                            │
│  ├─ red herring: 0.05 (1 correct, 1 wrong)                         │
│  ├─ impact: 0.05                                                    │
│  ├─ false_pos: -0.05 (1 low-confidence false positive)             │
│  └─ final_bonus = 0.10 + 0.05 + 0.05 - 0.05 = 0.15                │
│                                                                       │
└──────────────────────────────────────────────────────────────────────┘
                            ▼
┌──────────────────────────────────────────────────────────────────────┐
│ 6. CUMULATIVE SCORE                                                  │
├──────────────────────────────────────────────────────────────────────┤
│                                                                       │
│  Normalized episodic score:                                         │
│                                                                       │
│  cumulative_score = sum(step_rewards + final_bonus) / max_steps     │
│                                                                       │
│  Clipped to [0.0, 1.0]                                              │
│                                                                       │
│  Example (Easy task, 1 step):                                       │
│  ├─ step_reward[0] = 0.87                                          │
│  ├─ final_bonus = 0.15                                             │
│  ├─ sum = 0.87 + 0.15 = 1.02                                       │
│  ├─ max_steps = 1                                                   │
│  ├─ cumulative = 1.02 / 1 = 1.02                                   │
│  ├─ clipped = 1.00                                                 │
│  └─ observation.cumulative_score = 1.00                             │
│                                                                       │
│  Example (Hard task, 6 steps):                                      │
│  ├─ step_rewards = [0.8, 0.85, 0.75, 0.7, 0.8, 0.78]             │
│  ├─ final_bonus = 0.15                                             │
│  ├─ sum = 4.88 + 0.15 = 5.03                                       │
│  ├─ max_steps = 6                                                   │
│  ├─ cumulative = 5.03 / 6 = 0.838                                  │
│  └─ observation.cumulative_score = 0.838                            │
│                                                                       │
└──────────────────────────────────────────────────────────────────────┘

FINAL OUTPUT: observation.reward (step + episode bonus)
             observation.cumulative_score (normalized)
             observation.grader_feedback (NL)
```

```
All server files use duck-typing import pattern:
  try:
      from ..models import ...        # Relative (Package context)
  except ImportError:
      from models import ...           # Absolute (Docker container)
```
